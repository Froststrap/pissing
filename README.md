# PisS / PisSEd / PisSING

PlIST SErializING

---

## Why use this shit library?

It can be helpful for projects which need to create a PList file on runtime,
but you don't want to be boring and use PList, or Shell like a boring person,
instead you assert dominance and be stupid and use Rust types.

I'm using it for a build system which needs PList generation
to build Info.plist and *.entitlements files for manifests for Apple shipping.
